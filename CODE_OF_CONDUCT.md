# Code of conduct

This project aims to be a respectful, technically honest place to collaborate.

## Expected behavior

- Be respectful and professional.
- Assume good intent, but stay clear and direct about technical concerns.
- Give actionable feedback instead of personal criticism.
- Use synthetic or sanitized examples when discussing sensitive behavior.

## Unacceptable behavior

- Harassment, intimidation, or discrimination
- Personal attacks, insults, or sustained hostility
- Publishing private credentials, artifacts, or sensitive data from other people or environments
- Repeated bad-faith disruption of discussions, reviews, or issue threads

## Scope

This applies to issues, pull requests, reviews, discussions, and other project communication channels.

## Reporting

For conduct concerns, contact the maintainers through the repository's private or direct communication path when possible. For security problems, use [SECURITY.md](./SECURITY.md) instead of the normal conduct path.
